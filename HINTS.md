# #18 — Доступ к команде администратора

Когда #17 вольют, обнови эту ветку из `origin/main` и проверь, что владелец уже получает `admin` через `/start`.

1. Посмотри, как команда регистрируется для лички в [`handlers/health.py`](handlers/health.py) и как обработчик получает сессию в [`handlers/start.py`](handlers/start.py).
2. Найди профиль по ID отправителя. Вынеси решение о доступе отдельно от текста ответа, чтобы следующая команда могла переиспользовать проверку. Продумай, как обработчик ответит, если строки в базе нет.
3. За образец тестов возьми [`tests/test_start_flow.py`](tests/test_start_flow.py). Проверь вызов команды через Dispatcher с четырьмя вариантами профиля.

Пример: `admin` → доступ есть. `moderator`, `user` или отсутствие профиля → отказ.

К PR приложи скриншоты ответа владельцу и отказа второму аккаунту. Перед открытием PR убери этот файл из своей ветки.
