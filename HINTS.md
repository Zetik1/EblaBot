# #19 — Команда /myrole

Из папки EblaBot выполни `git fetch origin`, затем `git switch --track origin/feat/19-my-role`. Первая команда скачивает данные о ветках с GitHub, вторая открывает подготовленную ветку у тебя. Если уже открывал её раньше, хватит `git switch feat/19-my-role`.

1. Начни с [`handlers/health.py`](handlers/health.py). Найди, как `/ping` привязан к личным сообщениям. Для `/myrole` понадобится отдельный обработчик. Как подключить его, видно в [`handlers/__init__.py`](handlers/__init__.py).
2. В [`handlers/start.py`](handlers/start.py) найди ID отправителя и `session`. Сессия позволяет читать базу. В [`tests/test_roles.py`](tests/test_roles.py) найди пример `session.scalar(select(Person.role))`. Он показывает, как получить одно значение. Для `/myrole` подумай, как добавить условие по `Person.telegram_id`.
3. Сначала проверь результат на чистой тестовой базе. `/myrole` до `/start` → предложение запустить `/start`. После регистрации → «Ваша роль: пользователь». Затем проверь профиль с `moderator`, чтобы убедиться, что ответ берётся из базы.

К PR приложи два скриншота из лички, до `/start` и после. Перед открытием PR убери этот файл из своей ветки.
